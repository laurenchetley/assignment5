0.1 Water Quality Contract

0.1.1 Modules Parameters

0.1.1.1 Nutrients (Phosphorus and Nitrogen) Module

Input: Daily phosphorus and nitrogen nutrient inputs (mg/L)

  • Processing: Daily values aggregated to monthly means by water year (October - September)

  • Function: nutrient_function

Output: Total Productivity Risk Classifications:

Phosphorus = P and Nitrogen = N

  • Oligotrophic: Low Productivity: P < 0.01 mg/L, N < 0.35 mg/L

  • Mesotrophic: Medium Productivity: P 0.01 - 0.03 mg/L, N 0.36-0.65 mg/L

  • Eutrophic: High Productivity: P 0.03 - 0.10 mg/L, N 0.65 - 1.20 mg/L

  • Hypereutrophic: Very High Productivity: P > 0.1 mg/L, N > 1.20 mg/L

0.1.1.2

0.1.1.3 Dissolved Oxygen Module

Input: Daily dissolved oxygen levels (mg/L)

  • Processing: Daily values aggregated to monthly means by water year (October - September)

  • Function: dissoxygen_function

Output: Mean Dissolved Oxygen (DO) Classifications:

  • Excellent DO: > 8 mg/L

  • Moderate DO: 5 - 8 mg/L

  • Stressful DO: 2-5 mg/L

  • Hypoxic DO: <2 mg/L

0.1.1.4 Surface Water Temperature Module

Input: Daily surface water temperature (ºC)

  • Processing: Daily values aggregated to monthly means by water year (October - September)

  • Function: temperature_function

Output: Mean Temperature Classifications:

  • Cool: Below Average <13ºC

  • Mild: Average 13ºC - 22ºC

  • Warm: Above Average 22ºC - 30ºC

  • Hot: Boiling >30ºC

0.1.2 Water Quality Module Parameters

Inputs: Total productivity (mg/L ), mean dissolved oxygen (mg/L ), and mean surface water temperature (ºC)

  • Expected inputs: 365 daily observations per water year (October - September)

  • Functions used: temperature_function, nutrients_function, and dissoxygen_function

  • Processing: Monthly classifications from each module combined to assign overall water quality risk

Outputs: water_quality_model - Monthly water quality risk classifications

  • Low Risk - Oligotrophic, Excellent DO, Cool temperature

  • Moderate Risk - Mesotrophic, Moderate DO, Mild temperature

  • High Risk - Eutrophic, Stressful DO, Warm temperature

  • Extreme Risk - Hypereutrophic, Hypoxic DO, Hot temperature

# load in the model functions
source(here("scripts", "nutrient_module_script.R"))
source(here("scripts", "dissoxygen_module_script.R"))
source(here("scripts", "temperature_module_script.R"))

# load in the data
nutrientdata <- read.csv(here("data", "nutrient_data.csv"))
dissoxygendata <- read.csv(here("data", "dissoxygen_data.csv"))
temperaturedata <- read.csv(here("data", "temperature_data.csv"))

# run each model
nutrient_results <- nutrient_function(nutrientdata)
dissoxygen_results <- dissoxygen_function(dissoxygendata)
temperature_results <- temperature_function(temperaturedata)

# combine model outputs by month
water_quality_data <- nutrient_results |>
  select(month, nutrient_class = classification) |>
  left_join(
    dissoxygen_results |>
      select(month, dissoxygen_class = classification),
    by = "month"
  ) |>
  left_join(
    temperature_results |>
      select(month, temperature_class = classification),
    by = "month"
  )

# final water quality classification function
water_quality_model <- function(nutrient_class,
                                dissoxygen_class,
                                temperature_class) {
  
  if (nutrient_class == "Hypereutrophic" ||
      dissoxygen_class == "Hypoxic" ||
      temperature_class == "Hot - Boiling") {
    
    final_class <- "Extreme Risk"
    
  } else if (nutrient_class == "Eutrophic" ||
             dissoxygen_class == "Stressful" ||
             temperature_class == "Warm - Above Average") {
    
    final_class <- "High Risk"
    
  } else if (nutrient_class == "Mesotrophic" ||
             dissoxygen_class == "Moderate" ||
             temperature_class == "Mild - Average") {
    
    final_class <- "Moderate Risk"
    
  } else {
    
    final_class <- "Low Risk"
  }
  
  return(final_class)
}

# apply final model
water_quality_results <- water_quality_data |>
  mutate(
    final_water_quality = mapply(
      water_quality_model,
      nutrient_class,
      dissoxygen_class,
      temperature_class
    )
  )

# show final results
print(water_quality_results)

# Water Quality Visualization Script

library(tidyverse)
library(here)

# -------------------------------------------------------------------
# Plot 1: Monthly Final Water Quality Classification
#
# This figure displays the overall monthly lake water quality risk
# classification produced by the integrated water quality model.
# -------------------------------------------------------------------

wqm_classification_bargraph <- ggplot(water_quality_results,
       aes(x = month,
           y = final_water_quality,
           fill = final_water_quality)) +
  geom_col(color = "black", width = 0.7) +
  labs(
    title = "Monthly Final Water Quality Classification",
    x = "Month",
    y = "Water Quality Risk Classification",
    fill = "Risk Level"
  ) +
  scale_fill_manual(values = c(
    "Low Risk" = "#66c2a5",
    "Moderate Risk" = "#ffd166",
    "High Risk" = "#f4a261",
    "Extreme Risk" = "#d62828"
  )) +
  theme_minimal() +
  theme(
    plot.title = element_text(face = "bold", size = 16),
    axis.title = element_text(face = "bold"),
    axis.text.x = element_text(angle = 45, hjust = 1),
    legend.title = element_text(face = "bold")
  )
